14AppsSwitch

Alt-Tab style window switcher for macOSSélecteur de fenêtres façon Alt-Tab pour macOSmacOS 上的 Alt-Tab 式視窗切換器

Every window, not just apps.Toutes les fenêtres, pas seulement les apps.每一個視窗，而不只是應用程式。

Cmd-Tab only cycles between apps. If Terminal has 4 windows open and another app has 2, Cmd-Tab offers 2 slots — AppsSwitch offers 6, Windows Alt-Tab style, with a live thumbnail of every window.Cmd-Tab ne circule qu'entre les apps. Si Terminal a 4 fenêtres ouvertes et une autre app 2, Cmd-Tab propose 2 entrées — AppsSwitch en propose 6, à la façon d'Alt-Tab sous Windows, avec une miniature live de chaque fenêtre.Cmd-Tab 只在應用程式之間循環。若終端機開了 4 個視窗、另一個 app 開了 2 個，Cmd-Tab 只給你 2 個選項——AppsSwitch 給你 6 個，像 Windows 的 Alt-Tab 一樣，每個視窗都附即時縮圖。

Every window is one Tab awayChaque fenêtre à une touche Tab每個視窗都只差一個 Tab

Built on ScreenCaptureKit and a CGEventTap that owns the ⌥Tab gesture — no accessibility hacks, no third-party hotkey library.Bâtie sur ScreenCaptureKit et un CGEventTap qui possède le geste ⌥Tab — sans bidouille d'accessibilité, sans bibliothèque de raccourcis tierce.以 ScreenCaptureKit 與一個掌握 ⌥Tab 手勢的 CGEventTap 打造——不靠輔助使用的取巧手法，也不用第三方快速鍵函式庫。

  • Cycle every windowCirculez entre toutes les fenêtres循環切換每個視窗

    ⌥Tab moves forward, ⌥⇧Tab moves back, through every individual open window — not just between apps.⌥Tab avance, ⌥⇧Tab recule, à travers chaque fenêtre ouverte — pas seulement entre les apps.⌥Tab 往前、⌥⇧Tab 往後，逐一走過每個開啟中的視窗——而不只是在應用程式之間。

  • Live thumbnailsMiniatures en direct即時縮圖

    Each window is captured live via ScreenCaptureKit — a real preview, not a stale app icon.Chaque fenêtre est capturée en direct via ScreenCaptureKit — un vrai aperçu, pas une icône figée.每個視窗都透過 ScreenCaptureKit 即時擷取——是真正的預覽，而不是一張過時的應用程式圖示。

  • Exact activationActivation exacte精準切換

    Releasing Option activates exactly the window you selected — not just the app's frontmost window.Relâcher Option active exactement la fenêtre choisie — pas seulement la fenêtre au premier plan de l'app.放開 Option 鍵，啟用的正是你選中的那個視窗——而不只是該應用程式最前面的視窗。

  • Guided permissionsAutorisations guidées引導式權限設定

    A friendly onboarding requests Accessibility and Screen Recording, with deep links straight to System Settings.Un accueil clair demande l'Accessibilité et l'Enregistrement de l'écran, avec des liens directs vers les Réglages Système.友善的引導流程會請求「輔助使用」與「螢幕錄製」權限，並提供直接跳往系統設定的連結。

  • Keyboard-firstTout au clavier以鍵盤為先

    ⌥Tab / ⌥⇧Tab to cycle, release Option to activate, Esc to cancel.⌥Tab / ⌥⇧Tab pour circuler, relâchez Option pour activer, Échap pour annuler.以 ⌥Tab／⌥⇧Tab 循環，放開 Option 即切換，按 Esc 取消。

  • Menu bar onlyBarre de menus uniquement只待在選單列

    No dock icon, no main window — just a quiet menu bar item to check permissions or quit.Pas d'icône dans le Dock, pas de fenêtre principale — juste un élément discret en barre de menus pour vérifier les autorisations ou quitter.沒有 Dock 圖示，也沒有主視窗——只有一個安靜的選單列項目，用來檢查權限或結束程式。

Up and running in 30 secondsOpérationnel en 30 secondes30 秒內開始使用

Signed, notarized and Hardened-Runtime — it opens without any Gatekeeper warning.Signée, notariée et en Hardened Runtime — elle s'ouvre sans aucun avertissement Gatekeeper.已簽章、已公證並啟用 Hardened Runtime——開啟時不會出現任何 Gatekeeper 警告。

  1. Download. Grab the latest .dmg from GitHub Releases and mount it.Télécharger. Récupérez le dernier .dmg depuis GitHub Releases et montez-le.下載。從 GitHub Releases 取得最新的 .dmg 並掛載。

  2. Install. Drag AppsSwitch.app into /Applications.Installer. Glissez AppsSwitch.app dans /Applications.安裝。將 AppsSwitch.app 拖入 /Applications。

  3. Launch. Open it, grant Accessibility & Screen Recording when asked. Requires macOS 26 or later.Lancer. Ouvrez-la et accordez l'Accessibilité et l'Enregistrement de l'écran quand c'est demandé. Nécessite macOS 26 ou ultérieur.啟動。開啟它，並在詢問時授予「輔助使用」與「螢幕錄製」權限。需要 macOS 26 或以上版本。

Stop hunting for the right windowArrêtez de chasser la bonne fenêtre別再到處找那個視窗

Free and native. macOS 26 or later.Gratuite et native. macOS 26 ou ultérieur.免費、原生。macOS 26 或以上版本。
